# wanxiang_18_lookup
本仓库是基于 万象拼音方案（作者：amzxyz）的派生作品。理论上可以拓展为14键方案。
原项目采用 CC-BY-4.0 许可证。
本插件（Lua 辅助码脚本与简纯皮肤）目前仅在同文输入法上测试通过，其他平台尚未验证。

## ⚠️ 使用前请注意
使用本插件前，请确认你已使用 PRO 方案，并仔细阅读 万象方案文档 - 18键转写配置(https://amzxyz.github.io/doc/layouts)，确保已完成转写的相关配置。

## 📝 Lua 脚本说明
将 lua 脚本放置在 Rime 根目录下的 lua\wanxiang 文件夹中。

在 wanxiang_pro.custom.yaml 中添加以下配置：

```yaml
patch:
  engine/filters/@1: lua_filter@*wanxiang.wanxiang_18_lookup
```
## 🎨 皮肤说明
为方便英文输入，皮肤提供了两种切换方式：

右滑输入：在并击后的按键上右滑，可选中按键对应的第二个字母。

26键输入：长按 z 键，可在 18 键与 26 键布局之间切换，方便在 26 键上完成英文输入。
